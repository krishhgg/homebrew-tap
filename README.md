# krishhgg/homebrew-tap

Homebrew formulae for [sys1rust](https://github.com/krishhgg/sys1rust), which runs Laya's System 1 models on Apple silicon Macs.

```sh
brew install krishhgg/tap/sys1rust
sys1rust serve
```

The release workflow in krishhgg/sys1rust updates `Formula/sys1rust.rb` on every release. Do not edit it here by hand.
